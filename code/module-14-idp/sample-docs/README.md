# Sample Documents

Put sample invoices or receipts here (PDF or images: `.pdf`, `.jpg`, `.jpeg`, `.png`).

**Never commit real PII documents** — this directory is intentionally excluded from `.gitignore` only for the README itself. Add real invoices to your local `.gitignore` or keep them outside the repo.

Suggested test files:
- `sample-invoice.pdf` — a text-layer PDF invoice
- `sample-receipt.jpg` — a scanned or photographed receipt
- `sample-scanned.pdf` — a scanned PDF (triggers vision fallback)
